# Early-access source preview

This source preview covers five repositories: `crosspascal`, `crosspascal-opencv`, `crosspascal-leptonica`, `crosspascal-tvm`, and `crosspascal-convert`. The runnable example covers Geometry and DisjointSet on Windows with Delphi 37 Win64.

All 10 selected Pascal files passed formatting and the formatter check. The final RTL sources passed 541 Geometry checks and 9 DisjointSet checks, with no failures.

The corrected source candidate passed independent review. Publication preparation adds explicit license coverage, accurate capability descriptions, and file verification that accepts declared root Git metadata. The verifier still rejects unexpected source and build files.

A separate review accepted the measured OmDet differences for two fixed Windows CPU inputs. The original raw comparison failure remains part of that result. No OmDet model or runtime bundle has been added to this source preview.

The files are prepared for private testing. See the [GitHub release notes](https://github.com/pisarev/crosspascal/releases) for delivery details and clean-clone check results. Public access follows owner testing and separate approval. This preview is not a stable release.
